# Portofolio-Wiewien

> Modern, immersive personal portfolio website for **Wiewien Tancaniago** — Information Systems undergraduate at President University.

## ✨ Features
- **Cinematic Vector Stage & Parallax Background**: Japanese Edo/Fujisan vector art with interactive petal dynamics.
- **Dynamic Projects & Experience Showcase**: Featured works, live demo links, and detailed career milestones including Telkom Indonesia internship.
- **Interactive Chibi Cat Companion**: Cute interactive mascot with responsive animations, physics, and touch gestures.
- **Fast & Responsive**: Built with React 19, Vite, Lucide Icons, and Canvas Confetti.

## 🛠️ Tech Stack
- **Frontend**: React 19, Vite, Vanilla CSS Modules & Glassmorphism
- **Design & UI**: Responsive Layouts, Canvas API, SVG Animations
- **Hosting Ready**: Pre-configured for Vercel & Netlify

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
